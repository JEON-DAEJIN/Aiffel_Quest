- `report.md` — 실행 결과를 채워 넣는 리포트 템플릿

## Colab에서 여는 방법

### 방법 A — GitHub에서 바로 열기 (권장)
저장소가 GitHub(`JEON-DAEJIN/Aiffel_Quest`)에 올라간 뒤에는 아래 형식의 주소로 Colab이 바로 엽니다.

```
https://colab.research.google.com/github/JEON-DAEJIN/Aiffel_Quest/blob/main/강의정리/N036/실습/chapter08_colab.ipynb
```

브라우저 주소창에 위 URL을 입력하거나, Colab 첫 화면 → **파일 → 노트 열기 → GitHub** 탭에서
저장소 이름을 검색해 `chapter08_colab.ipynb`를 선택해도 됩니다.

### 방법 B — 파일 업로드
Colab 첫 화면 → **파일 → 노트 업로드**에서 이 폴더의 `chapter08_colab.ipynb`를 직접 올립니다.

## 실행 전 준비물
1. **OpenAI API 키** (실제로 켜져 있고 크레딧이 있는 키). 이미 한 번 채팅에 노출된 적이 있는 키를
   재사용하지 마세요 — 반드시 새로 발급받은 키를 쓰세요.
2. 런타임 유형: **CPU**로 충분합니다(GPU 불필요).

## API 키 등록 — Colab 보안 비밀 (반드시 이 방법 사용)
노트북 코드 셀에 키를 문자열로 직접 적지 마세요. 대신:

1. Colab 왼쪽 사이드바의 **🔑 (보안 비밀)** 아이콘 클릭
2. **새 보안 비밀 추가** → 이름: `OPENAI_API_KEY`, 값: 발급받은 키
3. **노트북 액세스** 토글 켜기
4. 노트북의 "0. 환경 설정" 섹션 셀을 실행 — 자동으로 `os.environ["OPENAI_API_KEY"]`에 등록됩니다

## 실행 순서
노트북을 위에서부터 순서대로 실행하세요.

1. **0. 환경 설정** — 라이브러리 설치 + API 키 등록 (가장 먼저, 반드시 1회 실행)
2. **1~3. 실전 재료 확보 → 본문 추출 → 출력 스키마** — Hacker News에서 실제 AI 기사 3건을 가져와
   본문을 뽑고 스키마를 정의
3. **실습: 기사 세 건을 취재해 본다** — 본문 실습, 언어 이탈 현상 관찰
4. **4. 기사 수만큼 펼치기** — LangGraph `Send` 팬아웃 실습
5. **🚀 더 해보기 1** — 한글 검사 + 재요청, 재시도 횟수 카운트
6. **🚀 더 해보기 2** — temperature 0 vs 0.7 비교

## 결과를 리포트로 남기기
전부 실행한 뒤, 아래 세 가지 출력을 그대로 복사해 Claude에게 붙여넣어 주세요.
- "실습: 기사 세 건을 취재해 본다" 섹션의 headline/summary/why + 한글 포함 여부
- 더 해보기 1의 "재시도가 발생한 기사: N / M건" 줄
- 더 해보기 2의 문장수·숫자 변동폭 비교 출력

이 세 가지를 받으면 `report.md`를 실제 실행 결과로 채워 완성합니다.

## 비용 안내
`gpt-4o-mini` 모델 기준, 기사 3건 취재 + 더 해보기 1(재시도 최대 1회씩) + 더 해보기 2(같은 기사 6회 재요약)를
전부 실행해도 API 호출은 대략 15회 안팎이며, 기사당 본문이 수천 자 수준이라 비용은 소액(보통 1달러 미만) 수준입니다.
