4-5. 단계 5 — Dockerfile · 로컬 빌드

  • staging에서 add-dockerfile 브랜치를 만들고 starter/Dockerfile과 starter/dockerignore를 복사했다. .gcloudignore는 이미 있었고 .env를 빼며 Dockerfile은 빼지 않는다
  • 5기준 검토 5개 모두 통과: 베이스 고정(python:3.13-slim-bookworm), tesseract-ocr+tesseract-ocr-kor 설치, .dockerignore에 .env, ${PORT:-8080}, USER appuser. Procfile·.python-version(3.13)과 FROM 버전이 일치했다

Cloud Build 로그의 Step 1~9에서 복원한 Dockerfile 명령(주석과 빈 줄은 로그에 없어 뺐다)

FROM python:3.13-slim-bookworm
RUN apt-get update && apt-get install -y --no-install-recommends tesseract-ocr tesseract-ocr-kor && rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
RUN useradd --create-home appuser
USER appuser
CMD ["sh", "-c", "uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-8080}"]
