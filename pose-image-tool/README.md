# 원하는 포즈로 이미지 만드는 도구

## 도구 설명
참조 사진에서 사람의 관절 위치(포즈)만 뽑아 스켈레톤으로 바꾸고, ControlNet의 Pose 조건으로 그 자세를 그대로 유지한 채 완전히 새로운 피사체·배경·스타일의 이미지를 생성하는 Colab 노트북입니다. (N017 "이미지 생성 어플리케이션 만들기" 챕터 8 과제)

## 사용법
1. [Colab](https://colab.research.google.com)에서 `pose_tool.ipynb`를 업로드해서 엽니다.
2. 상단 메뉴에서 `런타임 → 런타임 유형 변경 → T4 GPU`로 설정합니다.
3. 셀을 위에서부터 순서대로 실행합니다.
   - 2단계 셀에서 `samples/pose_01.jpg`, `samples/pose_02.jpg`를 함께 업로드합니다.
   - 5단계 셀의 `PROMPT_1`, `PROMPT_2`를 원하는 문장으로 바꿀 수 있습니다(자세는 어차피 고정되므로 자유롭게 바꿔도 됩니다).
4. 결과 이미지는 6단계에서 화면에 표시되고, `samples/output_01.png` / `output_02.png`로 저장됩니다.
5. 7단계 셀을 실행하면 결과 이미지·메타데이터(JSON)가 로컬 컴퓨터로 다운로드됩니다. 이 파일들을 `samples/` 폴더로 옮기면 됩니다.

## 테스트 결과
- 포즈 1: 한 다리로 서서 반대쪽 발을 무릎 옆에 붙이고 손을 가슴 앞에 모은 나무 자세(요가 Tree Pose) → 프롬프트: "갑옷을 입은 전사가 산 절벽 위에서 일출을 맞이하는 모습" → 결과: **잘 됨** — 한 다리로 서고 다른 다리가 접혀 올라간 구조, 가슴 앞에 모은 손 위치까지 원본 자세가 정확히 재현됨
- 포즈 2: 한 팔은 아래로 뻗고 반대 팔은 위로 뻗은 채 다리를 넓게 벌려 몸을 옆으로 기울인 삼각 자세(요가 Triangle Pose) → 프롬프트: "붉은 실크 드레스를 입은 댄서가 비 오는 밤거리에서" → 결과: **잘 됨** — 몸이 옆으로 기울고 한 팔이 위로 뻗은 구조가 그대로 유지됨

## 한계
- 포즈 참조 사진의 관절이 옷이나 각도에 가려지면(예: 손이 몸 뒤로 숨는 경우) 스켈레톤 추출 자체가 부정확해질 수 있음(이번 두 샘플에서는 발생하지 않음)
- 프롬프트로 표정이나 손가락 모양까지는 세밀하게 제어하기 어려움(N017 강의에서 배운 "프롬프트로 해결 안 되는 영역"과 동일한 한계)
- 참조 사진에 사람이 여러 명이면 OpenposeDetector가 여러 스켈레톤을 한꺼번에 뽑아 의도치 않은 결과가 나올 수 있음(한 사람만 있는 사진 권장)
