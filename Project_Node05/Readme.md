# 노드목록 05_Computating Thinking 과제 제출내용입니다.

나는 웹툰,웹소설 사업 도메인 15 년 차이고 매주 주요 플랫폼의 인기 웹소설·웹툰 Top3를 자동 수집·분석하여 성공 요인과 다음 트렌드를 도출하는 업무를 자동화/정리하고 싶어

## [분해]

① 플랫폼(카카오페이지,네이버시지르,리디,문피아) → ② 장르(웹툰/웹소설 내 각 하위장르)→ ③ 지표(조회수,결제,신규구독,순위변동 등) → ④ 작품속성(신작여부,소재,주인공직업군,세계관,전개방식)

## [패턴 인식]

반복적으로 인기 있는 장르, 소재, 캐릭터, 세계관, 전개 방식, 독자 반응 패턴을 분석

예를 들면

- 로맨스판타지가 3주 연속 상위권
- 회귀물이 대부분 포함됨
- 여성 독자 플랫폼에서는 치유물이 강세
- 카카오는 현대판타지
- 네이버는 학원물
- 주인공 직업군이 비슷함
- 초반 5화 몰입도가 높은 작품이 인기

> 이번 주 예시는 이렇지만 실제로는 매주 신선한 실데이터에서 유사 유형의 패턴을 새로 찾아야 함

## [추상화]

현재 독자가 가장 선호하는 핵심 서사와 성공 공식을 한 문장으로 요약

예를 들면

- 최근 인기작은 "빠른 전개 + 회귀 + 성장욕망"이라는 독자 니즈를 만족한다.
- 최근 플랫폼은 강한 세계관보다 감정 몰입형 스토리를 선호한다

## [알고리즘]

데이터 수집 → 전처리 → 작품 특징 추출 → 패턴 분석 → 플랫폼 비교 → 인사이트 생성 → 보고서 자동 작성

## [검증 기준]

**검증참여자**

- 10년차 웹소설 PD
- 10년차 웹툰 PD
- 일반 독자 1명

**판단 기준**

- 트렌드가 실제와 맞는가
- 작품 기획에 도움이 되는가
- 추천 기준이 납득되는가
- 새로운 인사이트가 있는가
- 단순히 이번주 Top3 랭킹이 얼마야, 조회수가 얼먀야 라는 답변은 하지 말아줘

① Executive Summary
