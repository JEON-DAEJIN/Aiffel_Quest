# Main Quest 2 — 웹소설 장면을 원하는 포즈의 웹툰 컷으로 만들기 (PoC)

N021 Main Quest 2 "내 도메인에서 AI로 개선 지점 찾아서 PoC 만들기" 제출용 저장소입니다.
[pose-image-tool](../pose-image-tool)(N017 챕터8 과제)에서 검증한 ControlNet Pose 기술을, 웹소설→웹툰 스토리보드 전환이라는 실제 도메인 문제에 적용했습니다.

## 실행 방법

1. [Colab](https://colab.research.google.com)에서 `webtoon_poc.ipynb`를 업로드해서 엽니다.
2. `런타임 → 런타임 유형 변경 → T4 GPU`로 설정합니다.
3. `samples/pose_03.jpg`가 아직 없다면, 무릎 꿇고 두 팔을 하늘로 뻗는 자세를 직접 촬영해 `samples/` 폴더에 추가합니다.
4. 셀을 위에서부터 순서대로 실행합니다 — 2단계 셀에서 `pose_01.jpg`·`pose_02.jpg`·`pose_03.jpg` 세 장을 함께 업로드합니다.
5. 6단계 셀에서 조건 A/B 이미지가 생성되고 화면에 나란히 표시됩니다.
6. 7단계 셀로 결과 이미지·메타데이터를 다운로드해 로컬 `samples/` 폴더로 옮깁니다.
7. [개선효과_검증.md](개선효과_검증.md)를 열어 실제 결과를 보고 표와 서술을 채웁니다.

## 재현 방법 (다른 사람이 실행할 때)

동일한 `samples/pose_01.jpg`·`pose_02.jpg`·`pose_03.jpg`, `webtoon_poc.ipynb`의 프롬프트와 `SEED=42`를 그대로 쓰면 같은 조건에서 같은 결과를 재현할 수 있습니다. 모델 다운로드(약 5GB) 외에 별도 설정은 필요 없습니다.

## 한계 · 다음 스텝

실제 실행 결과(`개선효과_검증.md`)에서 확인된 한계:

- **참조 포즈 사진의 정확도가 결과를 좌우한다**: 세트 3의 `pose_03.jpg`가 의도한 자세(무릎 꿇고 두 팔 하늘로)와 다르게 촬영됐는데도(회전·한 팔만 위로) 결과가 그럴듯하게 나와, 재현의 신뢰도를 확신하기 어려웠다. → 참조 사진 자체를 정확히 찍고 회전을 보정하는 절차가 선행되어야 한다.
- **텍스트 프롬프트만으로는 구도(전신/클로즈업)조차 통제하기 어렵다**: 세트 2의 조건 A가 우연히 클로즈업으로 나와,애초에 전신 포즈 비교가 불가능했다. 다음엔 프롬프트에 "full-body shot"을 명시해 조건 A·B 모두 같은 구도를 보장해야 한다.
- SD1.5 기본 체크포인트는 실사·애니메이션 채색 위주로 학습되어 있어, 순수 한국 웹툰 선화체 재현에는 한계가 있음 — 웹툰 스타일 LoRA/파인튜닝으로 개선 가능.
- 캐릭터 얼굴·의상이 세트마다 랜덤하게 나옴 — 특정 캐릭터를 고정하려면 캐릭터 LoRA나 IP-Adapter 추가 필요.
- 다음 단계: 프롬프트에 구도 명시 + 참조 사진 재촬영 후 재검증, 여러 컷을 이어 짧은 스토리보드 시퀀스로 확장, 또는 `pose-image-tool`처럼 GitHub Pages 데모로 배포.
