### 🧪 챕터08 실습 결과 — 2026-09-14, Colab 실제 실행

> "제목과 링크만 있는 상태"를 실제 Hacker News 기사로 직접 취재해봤고, 그 과정에서 그걸 검증하려던 **검사 코드 자체의 버그**까지 실행으로 잡아냈다.

| 발견 | 내용 |
|---|---|
| ✅ G1 관문 작동 확인 | 데모 사이트 링크 1건이 본문 추출 실패로 자동 탈락, 실제 뉴스 기사 2건만 취재 대상으로 통과 |
| ⚠️ 언어 이탈 재현 | 시스템 프롬프트·스키마 두 곳에 "한국어로 쓰라"고 명시했는데도 `headline` 필드가 영어로 나옴 — 같은 기사, 서로 다른 두 번의 호출에서 똑같이 재현 |
| 🐛 검사 코드의 버그 발견 | `headline+summary`를 합쳐서 검사하니 "0/2건 문제없음"으로 나왔지만, 필드별로 나눠 검사하자 실제로는 **"1/2건(50%) 재시도 필요"**로 결론이 뒤집힘 |
| 📉 측정 지표의 한계 | temperature 0→0.7 비교에서 문장수·숫자·영문고유명사 지표는 "차이 없음"으로 나왔지만, 실제 텍스트에는 "후아웨이" 비교 등 새 주장이 계속 추가됨 — 정량 지표가 실제 내용 변화를 놓침 |

**결론**: 자동 검사가 있다는 사실 자체는 안심의 근거가 되지 못한다 — 그 검사가 정확히 무엇을 확인하고 있는지까지 확인해야 한다.
